02 / HOW TO READ

这张表应该怎么看？

排名是入口，不是最终答案。

01

稳定优先

在线率看长期可用性，延迟看调用体验。两项应结合判断，单次测速不能代表真实稳定性。

02

核实模型

“支持某厂商”不代表所有模型都可用。正式使用前应核对模型版本、上下文限制和上游来源。

03

检查账单

确认输入、输出、缓存 Token、充值倍率和模型倍率是否透明，不要只比较首页标价。

04

控制余额

任何中转站都存在价格调整、模型下架或停止运营的风险。用多少充多少，不囤包月和大额余额。

03 / QUICK COMPARE

官方 API 还是中转站？

对隐私、稳定性要求高，并具备海外支付与网络条件时，优先官方；需要低门槛、多模型统一接入时，中转更方便。
